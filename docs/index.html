Workflow

/absol is the only front door. It opens a session, runs crash/pause recovery, prints a status banner, then watches the conversation and routes each turn to one of three modes — note-taker (capture), scratchpad (interactive freestyle), or pipeline (the formal, unattended flow). Pipeline is the default; scratchpad needs an explicit signal.

Reading the diagram

Solid arrows are control flow; dashed arrows are data (seeds feeding the pipeline, a refactor plan landing in plan.md, the executor's verify-fail loop). Everything inside pipeline runs without human input — every consequential decision is settled earlier, in shaping. absol-newproject (scaffold) and absol-migrate (schema upgrade) sit outside a run; absol-docs manages this very page.

Skills & agents

Each component has one job. skill are invoked through /absol or directly; agent are spawned by the orchestrator or planner; internal run only as part of a flow.

ComponentTypeRole
absol skill Front door. Opens a session, runs crash/pause recovery, prints a status banner, and routes each turn to note-taker, scratchpad, or pipeline. The only supported entry point.
note-taker skill Classifies a dropped thought into a durable [note] — bug → bugs.md, tech debt → tech-debt.md, idea/ambiguous → inbox.md.
absol-shaper skill Removes user-intent ambiguity before planning, one question at a time. Logs the locked-in decisions as shaper_notes. Interactive.
absol-research skill Read-only pre-planning pass. Fans out a dynamic workflow to map each seed's blast radius (consumers, sync hazards) and writes research_notes so plans respect the whole codebase.
absol-planner agent The brains. Turns a cohesive seed group into one PLAN of self-contained, vertical-slice tasks tagged with tier and order. Runs on opus.
absol-architect skill Standalone architecture review. Applies the deletion test, surfaces deepening candidates, drafts ADRs, and writes refactor PLANs. Does not change code.
absol-orchestrate internal Execution engine. Runs the plan's tasks serially and unattended, manages the test-fail auto-loop and review pass, hands off to the finalizer.
absol-executor agent Single-task executor. TDD for features and bigger bugs; direct edit for tweaks, chores, and low-risk fixes.
absol-reviewer
absol-reviewer-complex		 agent Review flagged or failed tasks — sonnet for routine passes, opus for architectural, high-risk, or inconclusive ones.
absol-scratchpad skill Interactive freestyle mode with documentation tracking underneath. Build, fix, explore, or discuss live; can dispatch a dynamic workflow for big interactive builds.
absol-finalizer internal Closes a run. Reconciles the event stream, writes a lean outcome-only archive, prunes done plans and resolved notes, and snapshots state.md.
absol-newproject skill Scaffolds a new project with the .absol/ layout, Docker files, .gitignore, and a git init. Skeleton only — the pipeline builds the rest.
absol-migrate skill Migrates a project to the current schema after a release that changes file shapes. Reads first, writes only on confirmation; git is the revert path.
absol-docs skill Manages the hosted documentation hub (this page lives here). Scaffolds, registers, and themes project docs served by homer.
